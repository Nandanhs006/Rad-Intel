What this system is

Rad-Intel classifies paediatric chest radiographs as normal or pneumonia, shows which regions drove the score, and writes a structured summary from those recorded outputs. Classification, explanation and language generation are kept separate so that every displayed sentence traces back to a number the model produced.

Restricted to technical research and education. It does not provide diagnosis, treatment, triage or autonomous decision support, and it is not a medical device.

Known limitations

  • Paediatric images from a single institution; nothing extends to other ages, institutions or acquisition protocols without external validation.
  • Labels collapse bacterial and viral pneumonia into one class.
  • No dependable patient identifier, so the split cannot guarantee patient-level independence.
  • Each configuration was trained once, so no result separates an architectural effect from seed variation.
  • Between 21% and 48% of model response falls outside the segmented lung fields, consistent with shortcut learning on this dataset.
  • Grad-CAM and LIME agree only weakly with each other; a heatmap shows model sensitivity, not pathology.
  • Generated summaries read as diagnostic to a reviewing clinician in half of sampled cases despite passing schema validation.
